# ダミーデータの投入手順

Docker 経由でダミーデータを投入します。

---
## 前提

- データベースが起動していること

---
## 手順

- backendディレクトリで実行します。
```bash
cd backend
docker compose up -d
```

```bash
docker run --rm \
  -v "$(pwd):/app" \
  -v gomodcache:/go/pkg/mod \
  -w /app \
  -e DATABASE_URL="sakuravel:password@tcp(db:3306)/sakuravel?parseTime=true&charset=utf8mb4" \
  --network app-network \
  golang:1.25-alpine go run ./seed/main.go
```

## 備考

- データを入れ直しやデータ量を変更する際にリセットを行う場合は以下を順に実行します。

```bash
docker compose stop
docker compose rm -f db
docker volume rm backend_mariadb_data
```

---
- データ量を変更したい場合は`./seed/main.go`内の以下の値を変更します。

```go
	numUsers         = 500
	numPosts         = 10000
	numFollows       = 50000
	numLikes         = 100000
	numReposts       = 20000
	numFootprints    = 20000
	numNotifications = 20000
```

- または、引数に `scale`をつけることで上記の件数をN倍に設定できます。

```bash
docker run --rm \
  -v "$(pwd):/app" \
  -v gomodcache:/go/pkg/mod \
  -w /app \
  -e DATABASE_URL="sakuravel:password@tcp(db:3306)/sakuravel?parseTime=true&charset=utf8mb4" \
  --network app-network \
  golang:1.25-alpine go run ./seed/main.go -scale 100 # <- コレ
```
