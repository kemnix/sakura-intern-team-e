# Sakuravel バックエンド設計書

## 概要

### 目的

Twitter 類似のマイクロブログ SNS「Sakuravel」のバックエンド API。

## システム構成

```
┌─────────────────────┐
│ Browser             │
└──┬───────────────┬──┘
   │ 画面(HTML/JS)  │ HTTP/JSON・SSE
┌──▼──────────┐ ┌──▼──────────────┐
│ Frontend    │ │ Backend API     │
│ Next.js     │ │ Go :8080        │
│ :3000       │ └──┬──────────────┘
└─────────────┘    │
                ┌──▼──────────────┐
                │ MariaDB :3306   │
                └─────────────────┘

※ ブラウザはバックエンドを直接呼び出す（フロントは中継しない）。
   呼び出し先は Frontend の `/api/config` が返す `API_URL` で決まる。
   別オリジンになるため、バックエンド側で CORS と Cookie の設定が必要。
```

---

## 技術スタック

- Go 1.25+
- MariaDB 10.11
- Docker
